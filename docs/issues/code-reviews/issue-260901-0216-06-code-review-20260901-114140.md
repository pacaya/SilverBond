### M1. "carrying each kind's configuration payload" is factually overbroad against `src/model.rs` (FIXED)
> **Fix:** replaced "carrying each kind's configuration payload" with "carrying per-kind configuration where the kind has one" — the qualifier the three bare unit variants require. Both reviewers VERIFIED_FIXED against `src/model.rs:693-752`.

**Severity:** MEDIUM · **File:** `docs/backend.md:61` · **Source:** Both (Claude found; Codex reversed its own clean claim to AGREE on cross-verify)

The entry states `NodeKind` carries "each kind's configuration payload". Three of the fourteen
variants are bare unit variants with no payload at all — `Approval` (`src/model.rs:704`), `Split`
(`:705`), `Collector` (`:706`) — declared with no field block. The project's own schema document says
so independently at `docs/workflow-schema.md:1102`, `:1107`, `:1111` ("Carries no config object — …
is a bare unit variant").

On a docs-truth issue whose stated purpose is making `docs/backend.md` agree with `src/model.rs`, an
unqualified "each kind" is a factual overstatement a reader acts on: they go looking for an
`approvalConfig` that does not exist.

Adjudication: kept. Claude raised it at confidence 70, raised to 75 after re-reading. Codex's Step-A
`VERIFIED CLEAN` item 3 had asserted the payload distinction was accurate, citing
`src/model.rs:696-752` — a range that *contains* the three counterexamples; on cross-verify Codex
re-read that range and reversed to AGREE. The orchestrator independently confirmed the three unit
variants at `src/model.rs:704-706` before adjudicating.

Note: the wording was inherited verbatim from the record's own `## Context Pack` (issue file line
62), so it was copied in good faith rather than invented. The Context Pack is a generated digest, not
the contract — the brief's Desired behavior asks only for "per-kind configuration", which the fix
below satisfies.

**Fix:** qualify the quantifier — "carrying per-kind configuration where the kind has one", or
equivalent wording that does not assert all fourteen variants carry a payload.
