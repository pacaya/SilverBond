### H1. Stale edge selection renders a blank inspector instead of the workflow inspector (FIXED)

> **Fix:** Parent restored `selectedEdge = $derived.by(...)` (existence-checked against `activeWorkflow.edges`) at `InspectorPanel.svelte:190-194`, branch reverted to `{:else if selectedEdge}` at `:1580` passing `edge={selectedEdge}`; `EdgeInspector` dropped its own `{#if}` guard and takes a concrete prop. Regression test `renders workflow inspector when edge selection is stale after undo` added at `InspectorPanel.test.ts:604-643`. Both reviewers VERIFIED_FIXED; the Claude reviewer re-ran its empirical add-edge→undo→render check (workflow inspector now renders, shape-identical to the pre-change baseline) and **proved the new test red** by reconstructing the broken semantics in a scratch copy — it fails at the `Name` textbox assertion, so it discriminates a blank panel, not merely absent edge controls.

**Severity:** HIGH · **File:** `ui/src/features/editor/InspectorPanel.svelte:1573` · **Source:** Both (CLAUDE-1 ≡ CODEX-1, mutual AGREE)

The parent's branch predicate changed from `{:else if selectedEdge}` — which required the edge to **exist** in the active document — to `{:else if store.selection.kind === "edge"}`, which tests the selection discriminator alone. `EdgeInspector.svelte:36` guards its own body with `{#if selectedEdge}` and renders nothing when the selected id resolves to no edge, so the `{:else}` workflow-level inspector at `InspectorPanel.svelte:1576` is no longer reachable in that state.

The state is reachable through a normal editor path: `store.addEdge` sets `selection = {kind:"edge", id}` (`workflowStore.svelte.ts:789`), and `undo()`/`redo()` (`workflowStore.svelte.ts:566-578`) restore a prior document **without** resetting selection. Add an edge, then ⌘Z (wired at `AppShell.svelte:280`, toolbar button at `AppShell.svelte:383`) and the whole inspector goes blank until the user clicks elsewhere.

The Claude reviewer verified this empirically, running an identical throwaway vitest against the working tree and against the stashed baseline: baseline after undo renders the workflow inspector; the working tree renders an empty `<div>` with only comment anchors. This directly violates the brief's central contract — "Rendered output and edit behavior are unchanged" — and no test covers it. Severity taken as HIGH (Claude's rating) over Codex's MEDIUM: it breaks the issue's defining preservation contract via a single keystroke.

**Fix:** Restore existence-based branching so parent and child agree on one source of truth — keep a `selectedEdge` derivation in the parent, branch the conditional on it, and pass `edge={selectedEdge}` into `EdgeInspector`. Having the child own the whole decision is **not** sufficient: the fall-through to the workflow inspector must be preserved.
