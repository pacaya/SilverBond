**Severity:** LOW · **File:** `ui/src/features/editor/WorkflowInspector.svelte:97` · **Source:** Claude (Codex AGREE)

**Fix:** Accept as recorded drift. Strict preservation would require the state to live above the branch, which the brief forbids ("the expanded-agent state … move[s] with it"), so there is no fix available inside this slice's constraints.

**Deferred because:** real (Codex confirmed the mechanism at both cited sites) but unfixable within this brief — the only strict-preservation fix is the one the brief explicitly rules out. The path is contrived, untested before and after, and the new collapse is arguably the better behavior. Recorded here so the drift is visible rather than silent; it is the accepted-risk counterpart the round-6 gate noted this record leaves implicit.
