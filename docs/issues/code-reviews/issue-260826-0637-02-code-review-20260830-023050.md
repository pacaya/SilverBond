**Severity:** LOW · **File:** `docs/api-reference.md:146` · **Source:** Claude

The request body deserializes into `TestStepRequest.mock_context: Option<NodeTestContext>`
(`src/api.rs:646-657`). `NodeTestContext` (`src/runtime.rs:1822-1843`) declares `variables`,
`nodeOutputs`, `previousOutput`, `branchOrigin`, `branchChoice`, all `#[serde(default)]` with no

only `{{var:NAME}}` keys present in it (`src/runtime.rs:7066`), so a reader copying this example gets
`{{var:topic}}` back unresolved.

example are not this issue's subject", and Out of scope says "nothing else in that section is".

severity is bot-deferrable.

**Fix:** Follow-up issue against the node-testing section: `"mockContext": { "variables": { "topic": "AI safety" } }`.
